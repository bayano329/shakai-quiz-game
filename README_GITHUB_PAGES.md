# 高校受験社会クイズアプリ 公開用ファイル

## 現在収録している問題

- 地理：700問
- 歴史：500問
- 合計：1200問

## 今回の修正

選択肢の表示順を、問題表示時に毎回ランダム化しました。

- JSON内の問題文・選択肢・解説は変更していません。
- 表示時に選択肢だけをシャッフルします。
- 正解位置も内部で自動追従するため、正誤判定は正常に動きます。
- 不正解時の「正解：①/②/③」も、シャッフル後の表示位置に合わせて表示されます。
- 地理・歴史・今後追加する公民にも同じ仕組みが使えます。

## レベル・経験値機能

- 出題数5問：正解1問につき1EXP
- 出題数25問：正解1問につき2EXP
- 出題数50問：正解1問につき5EXP
- 出題数100問：正解1問につき10EXP
- 経験値は、最後まで解き終えた結果画面でのみ加算されます。

## GitHub Pagesで必要な配置

`index.html`、`geography.json`、`history.json` をリポジトリ直下に置いてください。
