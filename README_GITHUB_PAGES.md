# 高校受験社会クイズアプリ 公開用ファイル

GitHub Pages公開用の最新版です。

## 現在収録している問題

- 地理：700問
- 歴史：500問
- 公民：300問
- 合計：1500問

## 収録科目

トップ画面の「科目」から以下を切り替えられます。

- 地理
- 歴史
- 公民

## 機能

- 3択クイズ
- 科目選択
- カテゴリー選択
- 出題数選択：5問 / 25問 / 50問 / 100問
- 難易度表示
- 頻出度表示
- 解説表示
- 苦手克服モード
- 学習記録
- レベル・経験値機能
- 選択肢のランダム表示

## 選択肢ランダム表示について

JSON内では正解位置が①に偏っていても、アプリ表示時に選択肢を毎回シャッフルします。  
正誤判定と不正解時の正解表示も、シャッフル後の位置に合わせて行います。

## レベル・経験値機能

- 出題数5問：正解1問につき1EXP
- 出題数25問：正解1問につき2EXP
- 出題数50問：正解1問につき5EXP
- 出題数100問：正解1問につき10EXP
- 経験値は、最後まで解き終えた結果画面でのみ加算されます。
- 途中でホームへ戻った場合、経験値は加算されません。
- 総獲得経験値はアプリ全体で共通です。

