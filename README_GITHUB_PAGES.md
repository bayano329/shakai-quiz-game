# 高校受験社会クイズアプリ 公開用ファイル

## 現在収録している問題
- 地理：700問
- 歴史：500問
- 合計：1200問

## レベル・経験値機能
- 出題数5問：正解1問につき1EXP
- 出題数25問：正解1問につき2EXP
- 出題数50問：正解1問につき5EXP
- 出題数100問：正解1問につき10EXP
- 経験値は、最後まで解き終えた結果画面でのみ加算されます。
- 途中でホームへ戻った場合、経験値は加算されません。
- 総獲得経験値はアプリ全体で共通です。

## GitHub Pagesで必要な配置
`index.html`、`geography.json`、`history.json` をリポジトリ直下に置いてください。
